# DashCraft

A clean-room, open-source, Rust-native alternative to Microsoft Power BI Desktop — connect to
data, shape it, model it, and build interactive reports. Built to the
[ArtCraft](https://github.com/storytold) crafting-app conventions. Native on macOS, Windows,
Linux and BSD; web via WASM.
